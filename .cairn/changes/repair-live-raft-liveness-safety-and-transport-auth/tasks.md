## Verification (2026-11-26, Raft protocol tasks 1–4)

Audit claims 1–5 were confirmed in code before the fix: opposing timer handles were never aborted and stale/role-mismatched timers returned `Err` (→ `Denied`, fatal in `serve_bound`); `ReadProbe` rejected `required_index > last_log_index`; duplicate `request_ref` validation scanned the whole log before truncation; `advance_leader_commit` emitted `N + 2` effects plus two executor fences; followers appended past `max_log_entries`; recovery snapshot installation retained the suffix unconditionally.

- Timers: `TokioReplicaPort` aborts the opposing handle on each arm; `stale_timer_event` (superseded election token, election timeout at a leader, heartbeat at a non-leader) yields a state-preserving, effect-free transition, and `Host::serve_bound` skips such queued timers.
- Commit advancement commits at most `max_effects_per_step − effects − 2 fences − 2 commit records` entries per step (124 for the reliability profile); later successful responses continue it. A follower at its log bound stores and acknowledges only the prefix that fits, so commit advances and the host's `snapshot_if_due` compacts before the leader resends.
- Recovery snapshot boundary (review fixes): `rejoin::repair::install_snapshot` keeps the suffix on a matching boundary term. On a mismatch it first repairs the log: local entries at or below the snapshot boundary take the copy every complete peer report holds within its commit (at the boundary only when its term equals the snapshot's), suffix `ReplaceWithCommitted` entries take the reporting peer's committed copy (identity- and commit-checked), `KeepLocal` entries are never dropped, and only `RemoveUncommitted` entries (with nothing resolvable after them) are truncated. The repair is one `PersistEntries` mutation (truncate from the first changed index plus the repaired entries and the confirmed tail) and `FlushLog`, ahead of `PersistSnapshot`, so a crash replays either the original or the repaired term-ordered log and a committed entry never exists only on peers. Installation is deferred, keeping all local evidence, while any suffix entry is `Wait`/unresolved, a needed committed copy is not yet reported, or the repaired log would still break term order; this preserves the storage-fault recovery requirement (keep unresolved local evidence) without wedging a replica whose faulty boundary or correct suffix peers can verify.
- Recovery evidence divergence (review fixes): before any rewrite or install, `check_snapshot_evidence` compares committed evidence only — peer-reported committed copies and locally committed entries — against the snapshot: the boundary term, and within the duplicate window the request the snapshot records at each index (both directions). The same index and term with another request fails closed with `FailureClass::MalformedObservation` ("Raft recovery evidence diverges from snapshot …"): no rewrite, no install, on the first attempt and after a restart. An uncommitted local boundary entry with the snapshot's term but another request is a repairable local fault: it is not a matching boundary, so it is rewritten from the verified committed copy in the pre-snapshot `PersistEntries` (or waits while no copy is verified). Tests: `repair::tests::{a_same_term_committed_copy_with_another_request_fails_closed_before_any_rewrite, a_restart_holding_the_contradictory_boundary_fails_closed_while_committed_evidence_contradicts, a_faulty_uncommitted_same_term_boundary_is_repaired_when_committed_evidence_agrees}`; the matching-boundary helper now uses the request the snapshot records at index 1.
- Behavior change: the existing test `peer_snapshot_installation_retains_an_unresolved_suffix_after_prefix_repair` asserted suffix retention across a mismatched boundary term where both peers lack the suffix entry (decision `RemoveUncommitted`); it is now `peer_snapshot_installation_discards_a_suffix_both_peers_lack_after_a_mismatched_boundary`. `live_denies_superseded_election_timer_before_protocol_effects` and the live-service stale-timer assertion now expect a benign no-op.
