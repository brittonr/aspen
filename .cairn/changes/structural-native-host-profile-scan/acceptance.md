a[structural-native-host-profile-scan.structural-field] The native host profile check accepts the canonical `materialized_output: Option<…NativeCallbackValue>` field in imported or path-qualified form, and rejects a different payload type or a renamed field.
a[structural-native-host-profile-scan.named-failure] Every required-source probe in the native host profile check names the missing literal and file when it fails.
a[structural-native-host-profile-scan.check-passes] `checks.x86_64-linux.native-system-extension-host-profile` builds on the change branch.
