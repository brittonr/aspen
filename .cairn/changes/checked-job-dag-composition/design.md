# Design

Aspen adds a distinct `job-dag-v2` envelope and explicit `selected-sequence-v2` profile; the v1 graph, node and edge meanings are unchanged. V2 reuses node/edge encodings while binding built-in implementation source and fixed signatures in canonical configurations, not invented installed artifacts. Exact u64-sequence schemas, distinct even/odd outputs, required/single versus variadic inputs, and optional Unit control edges are checked before execution. Port-labelled envelopes survive the existing executor/cache/result path; canonical graph/request refs bind routing and cache-visible meaning. Roots publish signature-ordered ports once and reject duplicates. No live handles or new effectful stage is admitted.

Captured authoring is a Linux imperative shell selecting the pinned Nickel CLI and measured `prlimit`, using existing Bounded Exec for finite input/output, deadline and process-group teardown. CPU/address-space limits bound construction as well as graph expansion. Explicit source/module/parameter inputs produce a closed DTO, normalize explicit instance/handle identities, encode canonical Preserves and invoke current JobDag admission. Source/export identities reuse the canonical Preserves string convention and link exact lowerer/evaluator/limiter and admitted graph refs. Origins are bounded author-declared instance/template/module/optional-port mappings; unavailable spans stay unavailable. Evaluation diagnostics are not disclosed. Construction/inspection never runs workload stages.

The shared Choregraph #6 construction library remains unavailable in the inspected provider: its public API exposes flat evaluated projections, not hygienic reusable typed fragments. Native Nickel functions and the Aspen DTO are usable without implementing a divergent general composition library. Shared nested-construction/law qualification remains an explicit upstream prerequisite, not a completed acceptance criterion. Local source was recovered to tmpfs after shared filesystem exhaustion; that is not NVMe or machine-loss persistence evidence.
