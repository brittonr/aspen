# Render workload design

The renderer is original AGPL-3.0-or-later code. Its manifest binds typed scene/schema, camera, dimensions, xorshift64* per-pixel/sample RNG and nonzero seed, bounded bounce count, row-major rectangular partition, RGB8/gamma2 output, component content identity and all task execution limits/profile. Canonical Preserves identity uses the existing codec, never JSON layout or Rust representation. Integer scene coordinates are millionths; ray arithmetic is f64. Determinism is declared only within the same qualified component/runtime/architecture profile; no cross-architecture equality is claimed.

At most 63 tiles plus one assembly task fit the 64-task limit. A literal assignment precedes dependency outputs in sorted tile-id order. Tile envelopes bind manifest identity, exact rectangle/index, pixel length and raw pixel digest. Assembly checks exact ordered coverage, envelope identity and digest, rejects duplicate/missing/substituted tiles, and recomputes expected pixels to reject correctly rehashed substitution. Recompute is deliberate correctness work, not cryptographic proof of remote execution. Final envelopes retain raw RGB8 plus manifest identity and digest; PPM is a presentation export. Bounded binary pixel payloads avoid JSON byte-array amplification. Manifest and assignment remain codec-framed typed values.

The default fixture is 640x360, 2 samples, 3 bounces, 8x4 tiles. Inputs, aggregate assembly inputs and final envelope remain below 4 MiB; even worst-case 63 tiles and 8 attempts remain below the 1 GiB retained-content ceiling for one isolated run. Existing stores remain authoritative for acceptance and retries. The standalone helper prepares inspectable inputs/job JSON and verifies final artifacts; shell entrypoints publish and execute through the existing CLI with separate controller/worker processes.

Authored tests are not executed evidence. Existing batch lifecycle tests/integrations own retries, cancellation, reconciliation and committed progress. A same-host script must run before any process qualification, and two physical hosts require separate evidence.
