# Design

The imperative wrapper captures locked, target-filtered Cargo metadata with default features, exports the existing release source profile and audit license policy, and invokes a checksum-pinned cargo-audit 0.23.0 against a caller-selected immutable RustSec Git checkout without fetching or registry lookups. The scanner checks the entire lockfile conservatively; the report selects findings reachable from molten in the target/default-feature metadata graph. JSON raw output, scanner executable/version, database revision/tree/date, exact lock/build/source/config bytes and prerequisites are retained in a bounded evidence directory. The normalizer independently remeasures bindings and validates scanner settings and database identity. Git/Radicle identities must match exact existing release-profile coordinates/revisions; broad organization prefixes are removed. SPDX grammar is parsed by the maintained spdx crate. All external packages need local license/notice bytes; absence is unavailable, not compliance. Exceptions bind advisory, exact package/version/source, owner, review, rationale and finite expiry; none are introduced. Existing license and release guards remain required separate evidence. A failed or stale prerequisite denies release even if advisories are empty.

Default molten on the explicit host target is the only selected profile. Optional features need a separately reviewed profile; all-features is prohibited. Raw-byte BLAKE3 refs are observations, not canonical admission receipts.

The Nix module builds the normalizer from the same script source using the existing registry lock cohort plus checksum-pinned SPDX 0.13.4. The runtime never resolves normalizer dependencies afresh. Notice capture precedes input binding; replay verifies retained notice bytes rather than recapturing ambient dependency files. Workspace notices reuse owned-root artifacts. Synthetic scanner-engine controls are distinct from the controls app's real maintained-database fixture, and neither is represented as a workspace release scan.
