## Why

Normal node startup currently invents a passing Octet receipt. Existing provenance commands accept caller references and cannot identify an executing candidate. Implement the user-authorized prerequisite as a product-owned Nix producer profile; reuse Nix build execution and output authentication, and preserve Octet's source-check-only claim boundary.

## What changes

Produce a detached versioned binding over measured compiled executable bytes, immutable source, complete build dependency closure, actual compiler toolchain, policy/profile, and the retained complete real Octet artifact cohort. Authenticate the containing output against an independently selected operator trust root; an evidence-carried key and unsigned caller references are never authority. Add pure bounded admission and a startup loader before any lifecycle mutation.

## Scope and nonclaims

Molten owns candidate profile and admission, Nix owns realization and signed NAR transport, Octet owns source checks. This does not establish compiler correctness, production readiness, deployment permission, or fast-path production admission. No Mantle source change is required to reuse the existing Nix protocol boundary. Production trust approval is external; an explicitly provisioned experimental signer can prove the mechanism without implying that approval.
