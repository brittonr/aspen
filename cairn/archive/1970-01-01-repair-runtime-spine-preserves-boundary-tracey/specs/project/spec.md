# Project Specification Delta

## ADDED Requirements

### Requirement: Direct Preserves boundary-profile evidence repairs

r[molten.project.runtime_spine_preserves_boundary_tracey.direct_repairs] The project MUST remove a Preserves boundary-profile requirement from inherited debt only when current implementation and focused validation directly support its complete accepted wording.

#### Scenario: Direct evidence is required
- GIVEN a Preserves boundary-profile candidate
- WHEN the repair batch classifies it as repaired
- THEN the manifest names one implementation path and one verification path
- AND both paths contain exact Tracey markers for that requirement

### Requirement: Exact Preserves boundary-profile manifest

r[molten.project.runtime_spine_preserves_boundary_tracey.exact_manifest] The project MUST record all nine candidates as direct repairs in typed deterministic evidence.

#### Scenario: Candidate accounting is exact
- GIVEN the Preserves boundary-profile candidate queue
- WHEN the evidence manifest is exported
- THEN every candidate appears exactly once
- AND the repair count matches the declared batch boundary

### Requirement: Fail-closed Preserves boundary-profile debt denial

r[molten.project.runtime_spine_preserves_boundary_tracey.growth_denial] The project MUST regenerate the exact inherited baseline and MUST fail validation when a repaired entry remains or a profile fixture changes its expected result.

#### Scenario: Baseline or fixture state drifts
- GIVEN the typed batch manifest, inherited baseline, and profile fixtures
- WHEN a repaired identifier remains or a fixture result changes
- THEN validation fails before the evidence batch is accepted

### Requirement: Preserves boundary-profile repair non-claims

r[molten.project.runtime_spine_preserves_boundary_tracey.non_claims] The project MUST state that this evidence repair does not prove transport liveness, actor authority correctness, replay completeness, Valence Evidence IR acceptance, universal adapter separation, complete runtime-spine coverage, release readiness, or whole-system correctness.

#### Scenario: Evidence is reviewed
- GIVEN a passing direct-evidence batch
- WHEN its scope is interpreted
- THEN only the nine named requirements leave inherited debt
- AND every listed non-claim remains outside the batch
